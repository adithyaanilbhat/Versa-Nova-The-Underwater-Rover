# Versa Nova: The Underwater Rover

## Project Overview

Versa Nova is an underwater robotic system designed for underwater inspection and visual monitoring of submerged structures, including dam walls and bridge pillars.

## Key Features

* Eight-thruster propulsion system
* Raspberry Pi 5 and Pixhawk-based control
* Camera-based underwater monitoring
* CNN-based crack detection
* Operator-controlled underwater movement

## Technologies Used

* Python
* TensorFlow
* Convolutional Neural Network (CNN)
* Raspberry Pi 5
* Pixhawk 2.4.8
