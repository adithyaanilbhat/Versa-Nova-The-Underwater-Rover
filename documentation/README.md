Technical Documentation — Versa Nova: The Underwater Rover

This directory contains the technical documentation for Versa Nova, an underwater robotic system developed for the visual inspection and monitoring of submerged structures, including dam walls and bridge pillars.

Documentation Contents

1. CAD Design

Contains the mechanical CAD models and related design files developed using Solid Edge.

2. Electronic Components

Provides information about the electronic and electrical components used in the rover.

3. Rover Block Diagram

Illustrates the main system components and their functional relationships.

4. Mathematical Analysis

Presents the mathematical calculations and engineering analysis related to the rover's propulsion and motion.

5. Working Principle

Explains the rover's operating principle, operator-controlled movement, underwater imaging, and CNN-based crack classification.

Project Scope

The project integrates mechanical design, embedded systems, propulsion, underwater imaging, and image-based crack classification. The documentation describes the implemented system while distinguishing current capabilities from potential future improvements.

Note

Certain design details are intentionally excluded from the public documentation pending further evaluation of intellectual property protection.
